# Knowledge Base — Index

Top-level router. Work knowledge only. Career and compensation material lives in `personal/` and is out of scope here.

**How to use this file:** find the domain, open that domain's `INDEX.md`, then open the specific files it names. Don't read past what you need.

## Adding a domain

A domain is a body of work large enough that its notes would crowd out others in a shared index — a team, a system, a long-running project. Create `domains/<name>/INDEX.md`, add a row above, and keep the row to one line.

Don't create a domain for a single note. Put it in the closest existing domain until there are enough related notes to justify splitting.
